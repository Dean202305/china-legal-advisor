# 手机端接入指引（豆包 / 元宝 / 千问 / Kimi / 智谱清言 / DeepSeek / ChatGPT / Gemini）

> 本文件同时会被 `scripts/build_kb.py --profile mobile` 复制进手机端知识库包，
> 方便你在手机上照着操作。

## 一、先理解一件事（很重要）

上面这些 App **运行在云端，无法调用你电脑上的程序**，也无法安装本地技能。
手机端唯一可行的方式是：

**① 把语料文件上传为「知识库」 → ② 把系统提示词粘贴到「智能体 / 自定义指令」**

上传这一步**必须由你在 App 内手动完成**——没有任何工具能代你操作手机 App 里的智能体创建界面。
本仓库能做的，是把这一步压缩到 **2 分钟**：文件格式选手机认得的、体积控制在上传限制内、
提示词准备好直接复制。

## 二、生成手机端文件包

```bash
python3 scripts/build_kb.py --profile mobile --zip
# 产物：dist/kb-mobile/ 与 dist/china-legal-advisor-kb-mobile.zip
```

| 文件 | 大小 | 用途 |
| --- | --- | --- |
| `00-先看这个-接入说明.md` | 3.5 KB | 本指引（手机端版） |
| `01-系统提示词-可复制.txt` | 5.7 KB | **复制粘贴到「人设 / 自定义指令」** |
| `中国法律条文-核心版-民法典与劳动.docx` | ≈246 KB | **优先上传这个**（民法典 + 劳动法 + 实务指南） |
| `中国法律条文-核心版-民法典与劳动.txt` | ≈940 KB | 平台不认 docx 时的备选 |
| `中国法律条文-全量版-33部法规.docx` | ≈339 KB | 核心版不够用时再传 |
| `中国法律条文-全量版-33部法规.txt` | ≈1.3 MB | 备选 |

> **为什么用 `.docx` 而不是 `.md`**：手机文件选择器常常**不显示 `.md` 文件**，
> 而 `.txt` 与 `.docx` 几乎所有 App 都认。DOCX 由纯标准库生成，Word / WPS / Pages 均可打开。
>
> 也可以直接从 [Releases](https://github.com/Dean202305/china-legal-advisor/releases)
> 下载打包好的 `china-legal-advisor-kb-mobile.zip`，省去自己生成。

## 三、怎么把文件传到手机

任选一种：

1. **微信/QQ 传给自己** → 手机上点开 → 「用其他应用打开 / 存储到文件」
2. 存进 **iCloud / 百度网盘 / 阿里云盘** → 在手机 App 里打开并保存到「文件」
3. **AirDrop**（iPhone ↔ Mac）
4. 邮件附件发给自己

关键是让文件出现在手机的「文件 / 我的文档」里，这样 App 的上传选择器才能选到。

## 四、各 App 操作卡片

> ⚠️ 各 App 的菜单位置会随版本调整。**按关键词找**通常更可靠：
> `知识库` / `上传文件` / `添加文档` / `本地文件` / `Knowledge` / `Files`
> `人设与回复逻辑` / `自定义指令` / `系统提示词` / `Instructions`

### 豆包
1. 打开豆包 →「我的」→「智能体」→「创建智能体」（或对话页右上角入口）
2. 「人设与回复逻辑」→ 粘贴 `01-系统提示词-可复制.txt` 全文
3. 「知识库」→ 上传 `中国法律条文-核心版….docx`
4. 保存 → 在该智能体对话里验证

### 腾讯元宝
1. 「我的」→「智能体」→「创建」
2. 填写「提示词 / 人设」→ 粘贴系统提示词
3. 添加「知识库」→ 上传 docx
4. 发布后使用

### 通义千问
1. 「智能体」→「创建智能体」
2. 「指令 / 人设」→ 粘贴系统提示词
3. 「知识库」→ 上传 docx
4. 保存并对话

### Kimi
- 无智能体平台，走**对话内上传**：对话框「+ / 附件」→ 上传 `核心版.docx`
- 每次新对话都需要重新上传（或用 Kimi+ 的文档/知识库能力）
- 第一句话建议写明：「下面是法律条文资料，回答法律问题前先在其中检索条文原文」

### 智谱清言
1. 「智能体」→「创建智能体」
2. 「人设」→ 粘贴系统提示词
3. 「知识库」→ 上传 docx

### DeepSeek
- 无智能体平台：对话框「+ → 上传文件」上传 docx（仅本次对话有效）
- 也可以在开放平台用 **API + 函数调用** 接入本仓库的 HTTP 服务（效果最好，见 `INTEGRATIONS.md`）

### ChatGPT
1. 「Explore GPTs」→「Create」（手机 App 同样入口，或网页版更顺手）
2. 「Instructions」→ 粘贴系统提示词（英文界面也可粘中文）
3. 「Knowledge」→ 上传 docx
4. 保存后可在手机 App 里使用该 GPT

### Gemini
1. 「Gems」→「New Gem」（手机 App 同样入口）
2. 「Instructions」→ 粘贴系统提示词
3. 「Knowledge / Files」→ 上传 docx
4. 保存后使用

## 五、上传后怎么验证

按顺序问三个问题：

1. **「劳动合同法第三十八条怎么规定的？」**
   → 应当返回条文原文，条号正确。若答不出或条号错，说明知识库没生效。

2. **「公司欠我 6400 元工资，还让我月底走人，我该怎么办？」**
   → 应当**先反问你几个关键事实**（入职时间、合同期限、有没有拿到合同、少发哪几个月…），
   而不是直接给结论。这说明"先问后答"的提示词生效了。

3. **「我这种情况能拿多少钱？」**
   → 应当写出**计算过程**（基数 × 月数），并在末尾给「总结回答」。

## 六、局限（请务必知道）

- 这是**检索增强**，不是硬约束：AI 仍可能引错条号、漏看文档或被长文档截断。
  **关键结论请自己核对条文原文**。
- 文件过大可能被平台拒绝或截断；**核心版更稳**，不够再加全量版。
- 语料是**快照**，且**不含地方性法规、地方政府规章与法院裁审指引**；
  最低工资、社平工资、工伤待遇、加班费基数等**地方标准**必须按当地口径另行核验。
- 本资料提供**法律信息**，不构成法律意见；具体争议请委托执业律师。
