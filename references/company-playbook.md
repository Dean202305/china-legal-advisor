# 公司法与企业法 · 检索地图

> **版本红线**：《中华人民共和国公司法》现行有效版本是 **2023 年 12 月 29 日修订、
> 2024 年 7 月 1 日施行**的版本（共 266 条）。2018 年修正的旧公司法条号（例如"认缴制无期限"
> 的旧规则）**不得**再引用。旧公司法系列司法解释（一）至（五）在 2023 年修法后经过修改/清理，
> 引用前必须确认现行有效性与条号对应关系。
>
> 本文件是**检索地图**；表中条号是入口提示，引用前必须
> `python3 scripts/law.py article 公司法 <条号>` 读原文。

## 一、设立与出资（2023 新法最大的变化）

| 问题 | 条文入口 | 要点 |
| --- | --- | --- |
| 股东承担什么责任 | 第 4 条 | 有限责任：以认缴的出资额/认购的股份为限 |
| 注册资本何时缴足 | 第 47 条 | 全体股东认缴的出资额由股东按章程规定**自公司成立之日起 5 年内缴足**（新增强制期限） |
| 出资形式 | 第 48 条 | 货币、实物、知识产权、土地使用权、股权、债权等可估价可转让财产 |
| 股东未按期缴资 | 第 49、50 条 | 向公司足额缴纳 + 赔偿损失；设立时其他股东承担连带责任 |
| 董事会催缴义务 | 第 51 条 | 董事会应当核查并催缴，未及时催缴造成损失的负责董事担责 |
| 股东失权 | 第 52 条 | 催缴 + 宽限期（自公司催缴书发出之日起**不少于 60 日**）→ 董事会决议发失权通知 |
| 抽逃出资 | 第 53 条 | 禁止；负有责任的董监高连带赔偿 |
| **出资加速到期** | 第 54 条 | 公司不能清偿到期债务时，公司或已到期债权的债权人可要求未届期股东**提前缴纳**出资 |
| 出资证明/股东名册 | 第 55、56 条 | 名册记载与登记 |
| 一人公司 | 第 23 条第 3 款 | 一人公司股东不能证明公司财产独立于自己财产的，对公司债务承担**连带责任** |
| 法人人格否认 | 第 23 条 | 第 1 款纵向否认；第 2 款横向否认（同一股东控制的多个公司互为连带） |

**易错点**：新法第 47 条的"5 年"是**法定期限**，不再是"章程自由约定且可无限期"。
存量公司有过渡安排（国务院《关于实施〈中华人民共和国公司法〉注册资本登记管理制度的规定》），
**问及"我公司 2050 年才到期要不要改"时必须查该过渡规定**，不能只引第 47 条。

## 二、股东权利与救济

| 问题 | 条文入口 |
| --- | --- |
| 查账（知情权） | 第 57 条（查阅章程、股东名册、股东会/董事会/监事会决议、财务会计报告；查阅**会计账簿、会计凭证**须说明目的，公司有合理根据认为不正当目的可拒绝） |
| 股东会职权与决议 | 第 58、59 条 |
| 表决比例 | 第 66 条（一般事项过半数；修改章程、增减注册资本、合并、分立、解散或变更公司形式须 **2/3 以上**） |
| 决议无效 | 第 25 条（决议内容违反法律、行政法规） |
| 决议可撤销 | 第 26 条（召集程序、表决方式违法/违章或决议内容违章；**60 日**内请求撤销） |
| 决议不成立 | 第 27 条 |
| 利润分配 | 第 210 条（弥补亏损、提取公积金后的税后利润分配）、第 212 条（决议作出后 6 个月内分配）、第 211 条（违法分配的退还） |
| 异议股东回购请求权 | 第 89 条（连续 5 年盈利且符合分配条件却不分配；合并分立转让主要财产；营业期限届满/解散事由出现而修改章程存续；第 3 款：控股股东滥用权利严重损害其他股东利益的回购） |
| 股东直接诉讼 | 第 190 条（董事、高管违反规定损害股东利益） |
| 股东代表诉讼 | 第 189 条（有限责任公司股东、股份有限公司连续 180 日以上单独或合计持股 1% 以上；前置程序：书面请求监事会/董事会起诉） |

## 三、股权转让

| 问题 | 条文入口 | 要点 |
| --- | --- | --- |
| 有限责任公司股权对外转让 | 第 84 条 | 向股东以外的人转让，**应当书面通知其他股东**，其他股东同等条件下有优先购买权（30 日内答复）；不再要求"过半数同意" |
| 未届出资期限即转让 | 第 88 条第 1 款 | 受让人承担缴纳义务；受让人未按期缴纳的，**转让人承担补充责任** |
| 未按期缴资/抽逃出资后转让 | 第 88 条第 2 款 | 转让人与受让人在出资不足范围内**承担连带责任**（受让人不知情且不应知情的除外） |
| 股权变动时点 | 第 86 条 | 受让人自记载于股东名册时起可主张行使股东权利 |
| 股份公司股份转让限制 | 第 157–166 条 | 发起人、董监高持股转让限制等 |

## 四、董监高责任（新法显著加重）

| 问题 | 条文入口 |
| --- | --- |
| 忠实义务与勤勉义务 | 第 180 条 |
| 禁止行为（侵占财产、挪用资金、私设账户、利用职权收受贿赂、接受他人与公司交易的佣金等） | 第 181 条 |
| 关联交易（自我交易） | 第 182 条（须报告 + 按章程经董事会或股东会决议） |
| 谋取公司商业机会 | 第 183 条 |
| 同业竞争 | 第 184 条 |
| 违反义务的赔偿责任 | 第 188 条 |
| 董事、高管执行职务造成他人损害 | 第 191 条（公司承担责任；董事、高管有**故意或重大过失**的也应承担赔偿责任） |
| 控股股东、实际控制人指示 | 第 192 条（与相关董事、高管承担**连带责任**） |
| 董事对第三人责任/清算责任 | 第 232、238 条 |
| 法定代表人 | 第 10、11 条（辞任之日起 30 日内确定新的法定代表人；辞任本身自辞任书送达公司时生效） |

**要点**：2023 新法把"董监高对第三人"和"控股股东指示"的责任写进了条文（第 191、192 条），
这是与旧法实务的重大差别；回答"挂名董事/挂名法定代表人要不要担责"时必须引这两条并说明
过错要件。

## 五、减资、合并、分立、解散、清算

| 问题 | 条文入口 | 要点 |
| --- | --- | --- |
| 减资 | 第 224 条 | 原则上**等比例减资**；弥补亏损的减资不得向股东分配、不得免除缴纳义务 |
| 违法减资 | 第 226 条 | 股东退还/恢复原状，董监高连带赔偿 |
| 合并 | 第 218–221 条 | 债权人通知与公告（10 日内通知、30 日内在报纸或国家企业信用信息公示系统公告） |
| 分立 | 第 222–223 条 | 分立前债务连带，另有书面约定除外 |
| 解散事由 | 第 229 条 | 章程期限届满、股东会决议、合并分立、吊销/责令关闭/撤销、司法解散（第 231 条，持股 10% 以上股东） |
| 清算义务人 | 第 232 条 | **董事为清算义务人**，解散事由出现之日起 **15 日**内组成清算组；未及时履行造成损失的承担赔偿责任 |
| 强制清算 | 第 233 条 | 逾期不清算，可申请法院指定清算组 |
| 简易注销 | 第 240 条 | 条件与全体股东承诺；承诺不实的责任 |
| 强制注销 | 第 241 条 | 被吊销等满 3 年未申请注销的，公司登记机关可强制注销 |
| 清算中债权申报 | 第 235 条 | 清算组应通知/公告债权人 |

## 六、配套规范与三个必须知道的衔接问题

### 1. 时间效力（"新法管不管我这件事"）

《最高人民法院关于适用〈中华人民共和国公司法〉时间效力的若干规定》（法释〔2024〕7 号，
2024-07-01 施行）——回答溯及力问题的**必查文件**。原则上新法适用于施行后的法律事实，
但该规定列明了若干**溯及适用**与**不溯及适用**的例外清单，必须逐条对照。

**特别注意**：法释〔2024〕15 号《关于〈中华人民共和国公司法〉第八十八条第一款不溯及适用的批复》
（2024-12-24 公布施行）明确：第 88 条第 1 款**仅适用于 2024-07-01 之后**发生的未届出资期限
股权转让行为；此前的此类纠纷按原公司法的规定精神处理。该批复对上述时间效力规定作了**限缩**，
涉及"未届期股权转让谁担责"时必须同时引用两件，**不能只引第 88 条**。

### 2. 存量公司的出资期限过渡（对第 47 条"5 年"的缓冲）

《国务院关于实施〈中华人民共和国公司法〉注册资本登记管理制度的规定》（国务院令第 784 号）：
2024-06-30 前登记设立的公司，有限责任公司剩余认缴出资期限**自 2027-07-01 起超过 5 年的**，
应当在 **2027-06-30 前**将剩余认缴出资期限调整至 5 年内并记载于公司章程，股东应在调整后的
期限内足额缴纳。故回答"我的公司 2050 年到期要不要改"必须引本规定，不能只引公司法第 47 条。

### 3. 司法解释（一）至（五）的条号陷阱 ⚠

**这五件解释截至 2026-09 仍为 2014/2020 修正版本，最高法未针对 2023 年修订的公司法作出
衔接修正**（新公司法的统一配套司法解释截至 2026-09 仍在制定中，2025-09-30 曾发布征求意见稿，
尚未公布施行）。因此它们的正文**沿用 2018 年修正前《公司法》的条号**，与现行公司法条号不一致。

**引用时必须做新旧对应，否则会指向错误的条文**。常用对应关系：

### 4. 其他配套

- 《最高人民法院关于适用〈中华人民共和国公司法〉时间效力的若干规定》——见上。
- 《中华人民共和国市场主体登记管理条例》（国务院令第 746 号）——登记、变更、注销程序。
- 公司法问题常与《民法典》合同编（股权转让合同、担保）、合同编通则解释交叉适用。

## 七、输出公司法答案时的固定检查项

- [ ] 是否使用了 2023 修订（2024-07-01 施行）版本？旧法条号有没有混入？
- [ ] 涉及出资期限时，是否区分了"新设公司"与"存量公司过渡"？
- [ ] 涉及股东连带责任时，是否说明了构成要件（滥用、财产混同、不能清偿到期债务）？
- [ ] 涉及决议效力时，是否分清"无效 / 可撤销（60 日）/ 不成立"三条不同路径？
- [ ] 涉及股权转让时，是否区分了"已届期"与"未届期"出资的不同责任？
- [ ] 涉及诉讼时，是否提示了代表诉讼的前置程序？
- [ ] 是否提示公司法问题常与《民法典》合同编、担保制度解释交叉适用？
- [ ] **个案是否已先按 `intake-questions.md` 补齐关键事实（尤其 2024-07-01 前后、签过什么字）？信息不全时是否列明了假设？**
- [ ] **回答末尾是否附了「总结回答」（定性＋依据＋金额＋风险＋动作＋时效）？**
