# 民法典与民事纠纷 · 检索地图

> 本文件是**检索地图，不是结论清单**。条号是入口提示，引用前必须
> `python3 scripts/law.py article 民法典 <条号>` 读到原文。
> 《民法典》条号用**中文数字**引用（如"第五百七十七条"），与法条原文保持一致。

## 二、总则编：几乎所有民事问题的第一站

| 问题 | 条文入口 |
| --- | --- |
| 民事法律行为有效要件 | 第 143 条（行为人具有相应行为能力、意思表示真实、不违反法律行政法规强制性规定、不违背公序良俗） |
| 无效情形 | 第 144、146、153、154 条（无行为能力人实施、虚假意思表示、违反强制性规定/违背公序良俗、恶意串通损害他人） |
| 可撤销情形 | 第 147–151 条（重大误解、欺诈、第三人欺诈、胁迫、显失公平） |
| 撤销权消灭 | 第 152 条（知道或应当知道撤销事由之日起 **1 年**；受胁迫自胁迫行为终止之日起 1 年；重大误解 **90 日**；自行为发生之日起 **5 年**未行使则消灭） |
| 效力待定（限制行为能力人） | 第 145 条 |
| 无权代理 / 表见代理 | 第 171、172 条 |
| 诉讼时效 | 第 188 条（**3 年**，自知道或应当知道权利受损害及义务人之日起；最长 **20 年**） |
| 时效中止 / 中断 | 第 194、195 条 |
| 不适用诉讼时效的请求权 | 第 196 条（返还财产/停止侵害等物权请求权、抚养费赡养费扶养费、其他） |
| 胎儿利益保护 | 第 16 条 |
| 个人信息保护 | 第 111 条 |

**易错点**：撤销权的 1 年/90 日/5 年是**除斥期间**，不适用中止中断，与诉讼时效是两回事；
回答"过期了没"必须区分两者。

| 定金 | 第 586–588 条（定金合同自实际交付定金时成立；数额不得超过主合同标的额的 **20%**；定金罚则；与违约金**择一**适用） |

**违约金调整的实务路径**（必须引原文 + 司法解释）：
《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》对
"过分高于造成的损失"（一般以超过损失的 30% 为参考）与举证责任有细化规定，
回答违约金问题时**必须同时检索该解释**。

## 十、输出民事答案时的固定检查项

- [ ] 是否先确定了法律关系（合同/侵权/物权/身份），再找对应的编？
- [ ] 是否区分了"无效 / 可撤销 / 效力待定"三种不同法律后果？
- [ ] 涉及期限时，是否区分了**诉讼时效**与**除斥期间**？
- [ ] 涉及违约金时，是否检索了合同编通则解释的细化规则？
- [ ] 涉及人身损害/离婚/继承金额时，是否提示按地方年度标准核验？
- [ ] 涉及诉讼时，是否给出了管辖法院与仲裁/诉讼的先后顺序？
- [ ] **个案是否已先按 `intake-questions.md` 补齐关键事实（尤其时间线与书面文件）？信息不全时是否列明了假设？**
- [ ] **回答末尾是否附了「总结回答」（定性＋依据＋金额＋风险＋动作＋时效）？**
