# 口语 → 法言法语 检索词对照表

用户不会说法条术语。**先翻译，再检索**：左边是用户可能说的话，右边是应当拿去 `law.py search` 的检索词。
多个检索词分批检索，避免一次塞太多词导致 AND 语义命中为零。

## 检索技巧

1. **短语加引号**：`law.py search "严重违反"` 避免被拆词。
2. **先宽后窄**：先用 1 个词看命中面，再叠加第二个词。
3. **命中为零就换词**：法律用语常有两套（"解除"vs"终止"、"赔偿金"vs"补偿金"），
   换同义词或改用 `--or`。
4. **限定文档更快**：`-d 劳动合同法`、`-c labor`。
5. **拿到条号后必须用 `article` 读全文**，再决定是否引用。
