# 时效性核验与语料库更新

法律问答最常见的失败不是"分析错"，而是**引用了已被修正或废止的条文**，
或者**拿全国性规定回答了一个地方标准问题**。本文件是引用前的最后一道关。

## 一、引用前的三问

1. **版本对吗？** `python3 scripts/law.py article <法规> <条号> --source`
   会打印该文件记录的 `version` / `effective` / `source`。
2. **还是现行有效吗？** 语料库是**快照**。若问题涉及近期修法动态、或该法规在
   语料库抓取日期之后有修正，必须联网核验。
3. **是不是地方标准问题？** 见下面第三节，这类问题必须按当地口径回答。

## 二、官方核验渠道（优先顺序）

| 渠道 | 地址 | 用途 |
| --- | --- | --- |
| 国家法律法规数据库（全国人大常委会） | https://flk.npc.gov.cn | **最权威**，法律/行政法规/地方性法规/司法解释的现行文本与修订记录 |
| 中国政府网 | https://www.gov.cn | 法律、行政法规、国务院文件的官方发布页（静态页可直接抓取） |
| 中国人大网 | http://www.npc.gov.cn | 法律草案、审议说明、法律全文 |
| 最高人民法院 | https://www.court.gov.cn | 司法解释全文、指导性案例、会议纪要 |
| 最高人民检察院 | https://www.spp.gov.cn | 检察解释与典型案例 |
| 人力资源社会保障部 | https://www.mohrss.gov.cn | 劳动、社保部门规章与政策 |
| 国家企业信用信息公示系统 | https://www.gsxt.gov.cn | 公司登记、股东、出资、处罚信息（办案取证用） |

> 注意：`flk.npc.gov.cn` 的接口有反爬保护，命令行 `curl` 取到的是 SPA 首页而不是数据。
> 核验时用浏览器打开该站检索，或改用 `www.gov.cn` 的静态全文页 / `web_search` +
> `web_fetch` 交叉比对两个官方来源。

## 三、必须按"地方口径"回答的事项（全国性条文不够用）

| 事项 | 为什么是地方问题 | 核验方向 |
| --- | --- | --- |
| 最低工资标准 | 省、自治区、直辖市分别规定并定期调整 | 省级人社厅最新通知 |
| 经济补偿封顶基数 | "当地上年度职工月平均工资的 3 倍" | 当地统计/人社部门公布数据 |
| 加班费计算基数 | 各地裁审口径不同（约定工资 / 正常工作时间工资 / 不得低于最低工资） | 省级高院或仲裁委指导意见 |
| 工伤待遇 | 一次性工伤医疗补助金、就业补助金标准由省级政府规定 | 省级工伤保险实施办法 |
| 社平工资 / 城镇居民人均可支配收入 | 用于工亡补助金、人身损害赔偿年度计算 | 国家统计局、地方统计局年度公报 |
| 竞业限制经济补偿标准 | 部分地区规定下限（如月平均工资的 30%） | 地方性法规或裁审指引 |
| 生育津贴与产假天数 | 地方奖励假天数不同 | 省级人口与计划生育条例 |
| 社保缴费基数上下限 | 每年调整，各地不同 | 当地社保经办机构公告 |

回答这类问题时，**必须**：给出全国性法律依据 + 明确说明"具体标准按当地口径" +
给出核验方法，而**不能**编造一个具体数字。若用户提供了所在城市，再联网查证并注明来源与日期。

## 四、更新语料库（加一部新法规）

```bash
cd <本技能目录>

# 方式一：从 URL 抓取（自动去 HTML 标签）
python3 scripts/add_document.py \
  --title "中华人民共和国XX法" --short "XX法" --category labor \
  --version "2025年X月X日修正" --effective 2026-01-01 \
  --source "https://www.gov.cn/..." --slug xx-law --from-url "https://www.gov.cn/..."

# 方式二：从本地已清理好的文本导入
python3 scripts/add_document.py --title "..." --short "..." --category company \
  --version "..." --effective 2025-01-01 --source "..." --slug yy-law --from-file /tmp/yy.txt

# 校验 + 重建索引
python3 scripts/law.py verify
python3 scripts/law.py index
```

`add_document.py` 会校验条号连续性、与 `--articles` 声明是否一致，并在失败时报警。

**语料文件头部字段说明**（`references/raw/*.txt`）：

```
---
title: 法规全称（引用时用这个）
short: 简称（检索时可用）
category: labor | company | civil | procedure
version: 通过/修正/修订说明（含日期与文号）
effective: 施行日期 YYYY-MM-DD
source: 抓取来源 URL
source2: 交叉验证来源 URL（可选）
fetched: 抓取日期 YYYY-MM-DD
articles: 正文最后一条的条号（用于完整性校验）
status: 现行有效 | 已修改 | 已废止
---
```

## 五、修法的两类陷阱

1. **条号漂移**：法律修订后条文常被整体重排（如 2023 年公司法由 218 条变为 266 条，
   条号与旧法不对应）。旧资料里的"公司法第 X 条"很可能是旧法条号，
   **必须回到语料库确认新条号，或明确标注"（2018 年修正版）第 X 条，现已调整为第 Y 条"**。
2. **新旧法衔接**：法律事实发生在新法施行前后的，要判断溯及力。
   公司法有专门的《时间效力规定》；民法典有《关于适用〈中华人民共和国民法典〉时间效力的
   若干规定》。民法典施行前的法律事实，原则上适用当时的法律（"法不溯及既往"），
   但有明确的例外清单，回答"新法管不管我这件事"必须查这两个文件。

## 六、语料库免责与边界

- 语料库是**离线快照**，抓取日期记录在每个文件的 `fetched` 字段，
  总览见 `references/CORPUS.md`。
- 语料库**不包含**地方性法规、地方政府规章、各级法院的会议纪要与裁审指引，
  也未包含全部司法解释。遇到这些内容必须联网核验，并在回答中说明依据来源。
- 若某问题检索不到对应条文，正确做法是**如实说明"语料库未收录，需核验"**，
  再用联网检索补充；**绝不允许**凭印象生成条文内容或条号。

## 七、近期重要法律变动（截至语料库抓取时点）

回答"现在怎么规定"时先看这张表——**很多旧资料、旧培训、旧判决引用的都是变动前的规则**。
回答中应主动说明版本，避免用户按旧法行动。

| 规范 | 变动 | 施行日期 | 影响 |
| --- | --- | --- | --- |
| 公司法 | 2023 年修订（266 条） | 2024-07-01 | 认缴出资 **5 年**法定期限、出资加速到期、董事为清算义务人、董监高对第三人责任、横向法人人格否认 |
| 公司法第 88 条第 1 款批复 | 法释〔2024〕15 号 | 2024-12-24 | 第 88 条第 1 款**不溯及适用**；2024-07-01 前的未届期股权转让按原公司法精神处理（构成对时间效力规定的限缩） |
| 公司法司法解释（一）～（五） | **未作衔接修正**，仍是 2014/2020 版本 | —— | 正文条号沿用**旧公司法**编号，与现行公司法不一致；引用前必须做新旧条号对应（见 `company-playbook.md` 第六节）。新公司法的统一配套司法解释截至 2026-09 仍在制定中（2025-09-30 曾发布征求意见稿） |
| 民事诉讼法 | 2023 年第五次修正（306 条） | 2024-01-01 | 涉外民事诉讼程序部分大幅修改；条号与 2021 版（284 条）不同 |
| 民法典合同编通则解释 | 法释〔2023〕13 号（69 条） | 2023-12-05 | 合同解释、违约金调整、代位权/撤销权、以物抵债等细化规则 |
| 民法典侵权责任编解释（一） | 法释〔2024〕12 号（26 条） | 2024-09-27 | 监护人责任、用人单位责任等 |
| 民法典婚姻家庭编解释（二） | 法释〔2025〕1 号（23 条） | 2025-02-01 | 重婚、同居、夫妻财产与债务等（**与解释（一）并行有效**，不是替代） |
| 劳动争议解释（二） | 法释〔2025〕12 号（21 条） | 2025-09-01 | 二倍工资按月计算、**竞业限制可被认定不生效**、**社保免缴约定无效**、**时效抗辩须在仲裁阶段提出**；废止解释（一）第 32 条第 1 款 |
| 仲裁法 | 2025 年修订（96 条，原 80 条） | 2026-03-01 | 商事仲裁制度重大修订（仲裁机构、涉外仲裁等） |

> 上表是**变动提示**，不是条文依据。具体条文一律回到语料库检索原文；
> 表内未列出的规范也可能已变动，必要时联网核验。

**回答这些主题时的强制动作**：

- **公司法**：默认用 2023 修订版；涉及 2024-07-01 前的法律事实，先查《时间效力规定》
  与法释〔2024〕15 号批复；引用公司法司法解释（一）～（五）时**必须先做新旧条号对应**
  （`law.py article 公司法解释（三） 13 --source` 会显示提示）。
- **劳动**：涉及二倍工资、竞业限制、社保、时效抗辩，**必须同时检索劳动争议解释（二）**。
- **民事**：涉及违约金、合同解释、代位权，**必须同时检索合同编通则解释**。
- **婚姻家庭**：涉及重婚、同居、夫妻财产，**必须同时检索婚姻家庭编解释（一）与（二）**。
- **仲裁**：区分**商事仲裁**（仲裁法，2026-03-01 起适用 2025 修订版）与
  **劳动仲裁**（劳动争议调解仲裁法）、**农村土地承包经营纠纷仲裁**、**体育仲裁**（各有专门规定）。
